First release of **Video Speed Controller for Firefox**, a Firefox port of
[Video Speed Controller](https://github.com/igrigorik/videospeed) 0.11.1 by
Ilya Grigorik and contributors.

- Packaged as a Firefox (128+) MV3 add-on.
- Settings now reach the page-world script in Firefox (`cloneInto()` in the
  content bridge).
- Twitch VODs and streams can again be played faster than 2x
  (igrigorik/videospeed#1651).
